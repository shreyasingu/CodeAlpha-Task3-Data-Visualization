# CodeAlpha-Task3-Data-Visualization
Power BI dashboard for analyzing Superstore sales, profit, orders, and regional performance.
## 📌 Project Overview

This project was completed as part of the **CodeAlpha Data Analytics Internship – Task 3: Data Visualization**.

The objective of this project was to transform Superstore sales data into an interactive and visually appealing **Power BI dashboard**.

The dashboard presents key sales and operational metrics through KPI cards, charts, and interactive filters, making it easier to understand business performance and explore the data.

---

## 🎯 Project Objectives

- Analyze Superstore sales data
- Create meaningful business KPIs
- Visualize sales performance across countries
- Analyze total orders and boxes shipped
- Identify important sales patterns
- Create an interactive Power BI dashboard
- Present data insights in a clear and professional format

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization
- **Microsoft Excel** – Dataset
- **Data Visualization** – Charts, KPIs and interactive filters
- **Data Analysis** – Sales and order analysis

---

## 📊 Dashboard Highlights

### 💰 Total Sales
Displays the overall sales generated from the Superstore dataset.

### 📦 Total Orders
Shows the total number of orders and provides an overview of order activity.

### 🚚 Boxes Shipped
Displays the total number of boxes shipped.

### 🌍 Sales by Country
A bar chart is used to compare sales performance across different countries.

### 🎛️ Interactive Slicers
Interactive slicers allow users to filter and explore the dashboard based on the available data.
